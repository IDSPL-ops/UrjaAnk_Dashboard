## Material limitations

Indoor buffering, accepted thermal constants, room AC effectiveness and latent response require matching indoor sensors and an explicit serving-AC selection. These calculations are implemented but no real indoor result is claimed. Diagnostic weather models describe association and may fail for short, sparse, constant or shifting operating periods. Conditional coefficient intervals exclude change-point-selection uncertainty. Flexible-event screening does not validate comfort, equipment control or savings. The matched benchmark uses same-hour station weather and metadata, with household behavior/equipment uncontrolled. Sparse peer availability is disclosed rather than silently relaxed.

Dependencies in `requirements.txt` are the installed versions used for checks. GitHub Actions runs the full included test suite and syntax checks. Hosting installation and a client-accessible deployment have not been performed.
